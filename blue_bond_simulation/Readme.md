# Blue Bond Simulation

Core Monte Carlo model for blended blue-bond governance and catalytic mobilization.

## Run

```bash
python -m blue_bond_simulation.code.run_blue_bond
```

Compatibility entrypoint:

```bash
python blue_bond_simulation/main.py
```

## Outputs

- `outputs/simulation_results.csv`
- `outputs/summary_statistics.csv`
- `outputs/chart*.png`
